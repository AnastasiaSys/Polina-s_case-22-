ПОЛИНА ВАЛЕРЬЕВНА — ДЕЛО №22

Файлы проекта:
- index.html — структура сайта и весь текст
- style.css — оформление, адаптивная верстка, цвета и типографика
- script.js — интерактивность: предпросмотр фото, расклад таро, тест и письмо

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для изменения текста редактируйте index.html.
4. Для изменения цветов и внешнего вида редактируйте style.css.
5. Для изменения загадок, таро и поведения кнопок редактируйте script.js.

Фотографии:
В блоке «Архив наших моментов» можно выбрать изображения с компьютера для предпросмотра.
Это локальный предпросмотр в текущем браузере. Чтобы фотографии были доступны всем при публикации сайта,
добавьте изображения в отдельную папку images и замените соответствующие карточки на img с путями к файлам.

Дизайн вдохновлён присланным референсом: тёмная фактурная шапка, винно-красные секции,
светлые карточки, редакционная типографика и мистическая эстетика. Внешние шрифты загружаются из Google Fonts.
